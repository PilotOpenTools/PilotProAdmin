# Журнал изменений - Pilot.ClientSdk (до 2.0.0 - Modules)

Формат: раздел `## [X.Y.Z] - дата` на каждую версию. Текст раздела становится описанием GitLab Release.

## [2.1.1] - 2026-11-10

- В сборку добавлена метка `AssemblyMetadata("PreviousNames", "Modules;113Modules.ext2")`, обещанная в 2.0.0: её не было, и при обновлении с 1.x админка не находила старый объект модуля.
- NuGet-пакет: зависимости `DocumentFormat.OpenXml`, `Humanizer.Core.ru`, `SharpVectors` больше не попадают в пакет (`PrivateAssets=all`); в пакете одна зависимость - `Ascon.Pilot.SDK`.
- В zip модуля `Humanizer.dll` версии 2.14.1 (была 3.0.x) - как заявлено в правилах библиотек админки и в Test-module.
- CI пакета, заявленный в 1.1.1, добавлен в `.gitlab-ci.yml`: `nuget_check`, `nuget_dev`, `nuget_rc`, `nuget_release` (`dotnet pack` и публикация в реестр проекта токеном job). `build_tests` собирает проект тестов, `test` запускает его на Windows-раннере.
- `.gitlab-ci.yml` приведён к `ci-template`: образы закреплены digest, добавлен `check_libraries`; job `release` убран - тег и GitLab Release ставит веб-админка.
- Выкладка из CI: ключи контуров `DEPLOY_KEY_TEST/_STAGE/_PROD` и токен job в `X-Job-Token`; текст коммита в `notes` не читается как путь к файлу.
- Статистика: текст ошибки обрезается до 2000 символов.
- `TypeExtensions.ConstAttrValue`: DTD в конфигурации атрибута запрещён.
- Исправлена гонка в `SdkSubscription`: подписка снимается раньше, чем задача получает результат (плавающий тест `Subscription_timeout_returns_partial_result`); снятие подписки синхронное (на UI-потоке клиента, через `Invoke`), а не отложенное через `BeginInvoke`.
- Несовместимость в CI: шаг входа в NuGet выдаёт токен job только источникам на хосте `CI_SERVER_HOST` (без порта). Если в `nuget.config` модуля тот же GitLab назван иначе (имя контейнера, IP), вход не выполнится и restore упадёт: пишите в `nuget.config` имя хоста, по которому GitLab видит сам себя.

## [2.1.0] - 2026-10-10

- Pilot.ClientSdk 2.1.0: эксперимент - общая библиотека Humanizer в zip модуля (`Humanizer.dll` рядом с модулем).

## [2.0.2] - 2026-10-10

- Окно «Загрузка модулей» в клиенте Pilot: колонки «Версия», «Статус», «Время» были пустыми. Тема Pilot задаёт неявный стиль строк ListView без колонок GridView; теперь у таблицы явные стандартные стили.

## [2.0.1] - 2026-10-10

- Окно «Загрузка модулей»: в таблице вместо названия модуля показывалось `StartupWindow+RowView`, а версия, статус и время были пустыми. Причина - строка таблицы была приватным вложенным классом, и WPF-привязки не могли прочитать её свойства.

## [2.0.0] - 2026-10-08

- Переименование: Modules / **Pilot.ClientSdk**. Сборка `113Pilot.ClientSdk.ext2`, пространство имён `Pilot.ClientSdk`, NuGet-пакет `Pilot.ClientSdk`, файл настроек `Pilot.ClientSdk.config.json`, лог `Pilot.ClientSdk.log`, переменная `CLIENTSDK_STATS_URL`, ключ общих настроек `Pilot.ClientSdk-…`.
- Модули нужно пересобрать: `using Modules` / `using Pilot.ClientSdk`, пакет `Modules` / `Pilot.ClientSdk`. Модули, собранные против `113Modules.ext2`, с 2.0.0 не загрузятся.
- Сборка помечена прежним именем (`AssemblyMetadata("PreviousNames")`): веб-админка обновит существующий объект модуля на серверах, а не создаст второй.

## [1.1.1] - 2026-10-08

- NuGet-пакет `Modules` только для компиляции: сборка в `ref/net48`, в bin и zip модулей не копируется.
- CI пакета: merge request - проверка сборки пакета, `dev` / `X.Y.Z-dev.N`, `release/*` / `X.Y.Z-rc.N`, `main` / `X.Y.Z` в реестре пакетов GitLab.
- CI-шаблон модулей: вход в реестр пакетов GitLab токеном job (источники из `nuget.config`).

## [1.1.0] - 2026-10-08

- Общие настройки Pilot «Модули общие настройки» (Сервис / Настройки): адрес и ключ сервиса статистики, интервал отправки, окно загрузки модулей, исключённые модули, пункты трея. Они важнее `Modules.config.json` и применяются без перезапуска клиента.
- Окно «Загрузка модулей»: новый режим «только при проблемах» (`startupWindowMode`: `always` / `problems` / `never`).
- Список модулей, которые не проверяются при запуске (`ignoredModules`).
- Пункты трея можно скрыть (`trayMenu`); в «Модули версии» видно, откуда взяты настройки.
- Кнопка «Проверить» в настройках: доступен ли сервис статистики (`/health`).

## [1.0.0] - 2026-10-08

- Статистика использования клиентских модулей / report-metrics-collector (`/api/module-events`), дашборд Grafana «Pilot - клиентские модули».
- Общие методы Pilot SDK для клиентских модулей (замена NugetPackage без NLog/Rx).
- Проверка модулей при старте клиента: контракт `IModule` / `StartupRunner.Run`, окно «Загрузка модулей».
- CI/CD: dev / тест, release/* / стейдж, main / прод + GitLab Release и NuGet-пакет Modules.

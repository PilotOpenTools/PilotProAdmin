# Журнал изменений - TestServerAction

Формат: раздел `## [X.Y.Z] - дата` на каждую версию. Текст раздела становится описанием GitLab Release.

## [1.0.4] - 2026-11-10

- Активность записывает в `documentVersion` текущие дату и время (UTC), а не `DateTime.MaxValue`; ошибки больше не подавляются, их фиксирует хост.
- `VERSION` берётся из версии сборки (`<Version>` в `.csproj`), а не дублируется в коде.
- Профиль отладки `debug`: `launchSettings.json` снова корректный JSON (обратные слэши в пути экранированы).
- Образец `debug.json`: `"apply": false`, чужой логин убран.
- `.gitlab-ci.yml` приведён к актуальному `ci-template`.

## [1.0.3] - 2026-10-10

- Проверка горячей замены через ServerHost: обновление модуля на сервере без перезапуска.
- Профиль отладки `debug`: путь к утилите относительно проекта.

## [1.0.2] - 2026-10-10

- Пример серверной активности `TestServerAction`: при срабатывании автоматизации записывает в атрибут `documentVersion` объекта-источника дату.
- CI из `ci-template`: dev / тест, release/* / стейдж, main / прод и GitLab Release.

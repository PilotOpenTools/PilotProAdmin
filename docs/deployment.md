# Развёртывание

PilotProAdmin и PilotMigration можно запустить отдельно от Pilot-Server, GitLab, PostgreSQL и S3. Выберите состав установки по инфраструктуре, которую уже обслуживает ваша команда.

| Вариант | Что запускать |
| --- | --- |
| Есть монолитный Pilot-Server | Установите админку, при необходимости добавьте сервис миграции. Укажите адрес действующего Pilot |
| Есть кластер Pilot-Server | Укажите адрес балансировщика. Для миграции предоставьте доступ к PostgreSQL кластера и файловому архиву |
| Нужен новый Pilot-Server | Установщик из релиза разворачивает монолитный Pilot для контуров, где выбрано «установить здесь» |
| Нужен кластер Pilot-Server | Подготовьте общие PostgreSQL, Redis и хранилище. Архив релиза `cluster.tar.gz` содержит Compose для узлов и балансировщика и скрипт инициализации конфигурационной базы |

[Быстрый старт админки](getting-started.md) · [Настройка кластерной миграции](../proadmin/migration/README.md#кластерный-pilot-server)

## Внешние сервисы

- **Pilot.** Если сервер уже есть, на вопрос установщика «Pilot <контур>» выберите «подключить существующий» и укажите адрес, доступный из контейнера админки. «Установить здесь» разворачивает контур на этой машине. Админка ставится всегда.
- **Git.** Подключите свой GitLab или поставьте новый на этой машине. Подключение GitHub.com доступно для публикации типов на тест. [Поддержка Git-хостинга](git-hosting.md).
- **PostgreSQL.** Для нового контура можно использовать существующий PostgreSQL: задайте в `.env` папки установки `<КОНТУР>_EXTERNAL_PG_HOST`, `<КОНТУР>_EXTERNAL_PG_PORT`, `<КОНТУР>_EXTERNAL_PG_DATABASE` и `<КОНТУР>_PILOT_PG_PASSWORD`. Подготовьте базу и роль `pilotuser` с правами владельца. Установщик проверит подключение и пропустит свой PostgreSQL для этого контура.
- **S3.** Для нового контура задайте в `.env` `<КОНТУР>_EXTERNAL_S3_URL`, `<КОНТУР>_EXTERNAL_S3_BUCKET`, `<КОНТУР>_S3_ACCESS_KEY` и `<КОНТУР>_S3_SECRET_KEY`. Установщик проверит доступ к существующему бакету и пропустит локальный RustFS. Укажите тот же архив при подключении базы в Pilot.

# Архитектура

| Компонент | Ответственность |
| --- | --- |
| PilotProAdmin | Razor Pages, сессии Pilot и GitLab, проверка прав, планирование и журнал операций |
| GitLab CI | Проверяет изменения и версии, собирает модули и вызывает API выкладки |
| GitHub Actions для типов | Подтверждает результат проверки влитого pull request |
| PilotMigration | Проверяет подключения и переносит базы PostgreSQL, архивы файлов и настройки Pilot |
| Pilot-Server | Хранит рабочие данные, метаданные и установленные модули каждого контура |

Админка обращается к Pilot и Git по API. Запросы выкладки из GitLab CI проверяются по токену задания и ключу контура. Миграция подключается к PostgreSQL и файловому архиву напрямую. Варианты архива включают локальную файловую систему и S3-совместимое хранилище.

Контуры и мониторинг настраиваются независимо. [Структура стека и режимы развёртывания](https://github.com/PilotOpenTools/PilotProAdmin/tree/main/stack).
